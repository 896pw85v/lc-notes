2. Add Two Numbers

``` Java
/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
        if (l1 == null) return l2; // checks l1 first
        if (l2 == null) return l1; 
        int sum = l1.val + l2.val;
        if (sum >= 10) {
            // add to l2 
            if (l2.next == null) l2.next = new ListNode(1, null);
            else l2.next.val += 1; 
            return new ListNode(sum - 10, addTwoNumbers(l1.next, l2.next));
        } else {
            return new ListNode(sum, addTwoNumbers(l1.next, l2.next));
        }
    }
}
```

This is a failed solution even though it passed the test cases. Because when l2 is longer than l1, the 10 in l2 will be directly returned: 
```
l1 = [9, 9]
l2 = [9, 9, 9]
            ^ returned
re = [8, 9, 10]
```

One improvement is the following. It works by prolong `l1` with 0 and add the 10 to `l2`, so the only way to exit is when both reaches the bottom. : 
``` Java
class Solution {
    public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
        if (l1 == null && l2 == null) return null; // check when both reaches end
        if (l1 == null) l1 = new ListNode(0); // manually prolong l1
        if (l2 == null) return l1; 
        int sum = l1.val + l2.val;
        if (sum >= 10) {
            if (l2.next == null) l2.next = new ListNode(1, null);
            else l2.next.val += 1; 
            return new ListNode(sum - 10, addTwoNumbers(l1.next, l2.next));
        } else {
            return new ListNode(sum, addTwoNumbers(l1.next, l2.next));
        }
    }
}
```
It works perfectly. When `l1` is shorter, it is prolonged with zero to continue; when `l2` is shorter, there will be no trailing 10 because 10 is carried to l2. Downside is if `l2` is significantly larger, `l1` will be prolonged to the same length, repeatedly creating new `ListNode` and consuming memory. 
```
l1 = [0]
l2 = [0, 1]
           ^ l1 prolonged with 0
re = [0, 1]
```
Another improvement: 
``` Java
class Solution {
    public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
        if (l1 == null) return l2; 
        if (l2 == null) return l1; 
        int sum = l1.val + l2.val;
        if (sum >= 10) {
            l1.next = addTwoNumbers(l1.next, new ListNode(1));
            return new ListNode(sum - 10, addTwoNumbers(l1.next, l2.next));
        } else {
            return new ListNode(sum, addTwoNumbers(l1.next, l2.next));
        }
    }
}
```
I can't do better. Now when it needs to carry a 10, simply recurse `l1` with a 1, which takes nearly zero time and costs space only when it needs to carry. Less check, more elegant.
